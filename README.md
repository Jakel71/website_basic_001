What does this site?

Used librarys:

- https://unpkg.com/supersimpledev/babel.js (babel library)
- https://unpkg.com/supersimpledev/react-dom.js (react library)
- https://unpkg.com/supersimpledev/react.js (react library)
- https://unpkg.com/supersimpledev@8.6.4/external-library.js (test library, to make sure, external librarys work)
